# 致爱丽丝·利德尔

《致爱丽丝·利德尔》是一座献给爱丽丝·利德尔、也献给一切逝去之物的数字哥特纪念碑。合集名为《玫瑰与灰烬》哥特式星座盘，主场景为「利德尔墓地」——所有子项目从这里进入。

> 项目仓库：https://github.com/SgfKrc/Mygothic

这是一个非盈利的数字艺术品项目。全部素材（背景图、字体、未来音频）仅限作者个人展示使用，不对外传播或商用。

## 项目定义

- **项目名**：致爱丽丝·利德尔
- **合集名**：《玫瑰与灰烬》哥特式星座盘
- **主场景**：利德尔墓地，所有子项目从这里进入
- **第一期范围**：利德尔墓地主场景（主页导航中枢）+ 图书馆之梦
- **其余展馆**：玫瑰温室、钟楼、塔罗圣堂、骨园、鸦巢、遗骨室、星盘台、冬之钟——已开放展馆从墓地入口进入，星盘台使用本地预置样本情绪数据

完整产品规格与视觉技术蓝图见 [`docs/gothic-collection-spec.md`](docs/gothic-collection-spec.md)。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173/`。

可用路径：

- `#/cemetery`：利德尔墓地主场景
- `#/library`：图书馆之梦
- `#/gothic-orbit`：哥特式星座盘
- `#/winter-bell`：冬之钟
- `#/unavailable`：尚未开放展馆状态

## 技术栈

- 构建：Vite + TypeScript
- UI：React（CSS Modules / 普通 CSS）
- 绘制：Canvas 2D 为主，SVG 用于可缩放牌面、纹章与建筑线稿
- 动效：CSS transitions / animations
- 音频：Web Audio API（合成环境音）
- 路由：hash 路由（静态托管直接刷新可用）

## 当前实现

- Canvas 多层绘制墓地与图书馆，包含雨、雾、火焰、烛光、建筑和材质纹理；墓地 V2 增加透视砖路、积水、碎石、草簇、钟楼分缝和局部像素材质，V3 将钟楼改为尖顶结构并将三角形树替换为多分枝枯树，V4 增加镂空拱窗、玫瑰窗窗棂、屋顶装饰、立面浮雕和塔冠天使雕像，V5 增加外侧副塔尖顶与双层飞扶壁；图书馆 V6 细化多层窗外哥特建筑与屋脊结构，V7 扩展为可左右探索的长廊地图，增加多层视差、右侧画像墙和去白底画像处理，V8 修复尖塔悬空基线并保留人物白色衣物，V9 将展馆更名为图书馆之梦，缩小画像、下移画像热点、加入左侧哥特门与素材文案随机弹层，并以错缝短竖线补足木地板质感；V10 将室内拆成后墙、墙面、家具、地板四层视差，补充天使雕像、控制台、阅读椅、立式复古灯和动态光晕，重绘门、书架与画像内衬；V11 以等比 cover 裁切修复画像底色，增加左右近景石柱和边界构件，继续细化门板与书架冠饰；点火态增加暖色照明，主体轮廓保持平滑手绘风格。
- 墓地热点可进入图书馆之梦、哥特式星座盘和冬之钟，其余热点显示封存状态。
- 图书馆之梦支持雨声/壁炉开关、孤本随机翻页、素材文案弹层、侧门反馈和专注模式。
- 环境音使用 Web Audio API 生成短反馈；BGM 等待作者个人改编音轨接入。
- 支持键盘操作、可见焦点、`prefers-reduced-motion` 和移动端降级。

## 内容数据

- 图书馆之梦孤本文案共 12 条（3 条作者句 + 9 条已通过补写句），统一以「来自心底」标签接入 `src/data/libraryPoems.ts`，可在不修改 Canvas 逻辑的情况下替换或增加内容。
- 墓碑、箴言、诗句、按钮反馈均使用独立数据文件，避免写死在绘制逻辑中。

墓地视觉迭代记录位于 `local_docs/视觉素材迭代记录.md`。当前 V11 已将展馆统一命名为“图书馆之梦”，修复窗外尖塔悬空基线、保留画像人物的白色衣物，缩小画像并增加侧门交互；室内改为多层视差并补充雕像、立灯、家具和画像内衬；继续使用 `local_docs/90年代复古动漫风格 (1).png` 对应的 `public/library-cathedral-bg.png` 与 `local_docs/image.png` 对应的 `public/library-portrait-source.png`；后续重绘先在 `local_docs/` 验证，再复制稳定版本到 `public/`。

## 素材与版权说明

`local_docs/` 是素材源文件与迭代记录目录。墓地背景 `local_docs/90年代复古动漫风格.png`、图书馆底图 `local_docs/90年代复古动漫风格 (1).png` 和画像参考 `local_docs/image.png` 仅在确认稳定后复制到 `public/`；当前运行时副本为 `public/library-cathedral-bg.png` 与 `public/library-portrait-source.png`。项目素材（背景图、头像、字体、未来音频）仅限作者个人展示使用，不对外传播或商用。

## 文案说明

- 中文优先，数据结构预留中英双语；副标题英文为 **Shadows of Never-were**。
- 墓碑主文案：**「这里埋着三个爱丽丝。」**；初次进入题词：「只是睡着了。」
- 墓碑不显示 Alice Liddell 的历史注记，属虚构叙事场景。
- 由 AI 补写的句子须经作者逐条审定后方可进入公开版本（见规范第 9 章）。
